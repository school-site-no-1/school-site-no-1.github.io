Теория: Обработка, кодирование и поиск информации

Быстрый переход:
  • 1. Обработка информации
  • 2. Кодирование
  • 3. Условие Фано
  • 4. Поиск информации

1. Обработка информации

Информационный процесс — совокупность последовательных действий (операций), производимых над информацией для получения какого-либо результата.

Выделяют три основных типа: обработка, хранение и передача информации.

Обработка информации — это целенаправленный процесс изменения содержания или формы представления информации.

Два типа обработки:

  1. Получение нового содержания (вычисления, логические рассуждения).
  2. Изменение формы представления (кодирование, структурирование, поиск).

2. Кодирование информации

Кодирование — преобразование информации в форму, удобную для хранения, передачи, обработки.
Код — система условных обозначений (кодовых слов).
Кодовая таблица — совокупность кодовых слов и их значений.

Виды: Равномерные (ASCII) и Неравномерные (Морзе).

3. Условие Фано и префиксные коды

Префиксный код — код, в котором никакое кодовое слово не является началом другого.

Условие Фано: Для однозначного декодирования достаточно, чтобы ни одно слово не было началом другого (прямое условие) или окончанием другого (обратное условие).

Дерево кодирования: Наглядно представляет префиксные коды. Листья дерева — коды.

4. Поиск информации

Метод последовательного перебора: для неструктурированных данных. В среднем N/2 просмотров.

Метод половинного деления (бинарный поиск): для упорядоченных данных. Сравнение с центром, отбрасывание половины. Работает быстро.

Задача 1. Примеры процессов обработки информации

Условие: Приведите примеры процессов обработки информации. К каким типам обработки информации относятся эти процессы?
Краткое решение и ответ
  • Приготовление еды: Продукты → Рецепт → Блюдо. (Изменение формы).
  • Решение примера: Числа → Вычитание → Результат. (Вычислительная).
  • Поиск в интернете: Запрос → Алгоритм → Ссылки. (Поиск и сортировка).
Подробное решение

Пример 1. Приготовление блюда по рецепту.

Исходные данные — набор продуктов. Правило обработки — рецепт (последовательность действий: нарезать, смешать, запечь). Результат — готовое блюдо. Тип обработки — изменение формы представления: исходные продукты преобразуются в новую форму, при этом их состав не меняется принципиально, но меняется структура и внешний вид.

Пример 2. Решение арифметической задачи.

Исходные данные — числа из условия. Правило обработки — алгоритм вычисления (сложение, вычитание, умножение). Результат — новое число, которое не содержалось в исходных данных. Тип обработки — получение нового содержания (вычислительная обработка).

Пример 3. Поиск информации в интернете.

Исходные данные — поисковый запрос. Правило обработки — алгоритм работы поисковой системы (индексация, ранжирование). Результат — список ссылок, отсортированный по релевантности. Тип обработки — поиск и сортировка (изменение формы представления).

Пример 4. Перевод текста с одного языка на другой.

Исходные данные — текст на иностранном языке. Правило обработки — словарь и правила грамматики. Результат — текст на русском языке. Тип обработки — изменение формы представления (содержание сохраняется, меняется язык).

Программное решение (Python) 
# Демонстрация вычислительной обработки
def calculate(a, b, operation):
    """Обработка информации: получение нового содержания"""
    if operation == '+':
        return a + b
    elif operation == '-':
        return a - b
    elif operation == '*':
        return a * b
    elif operation == '/':
        return a / b

# Исходные данные
x, y = 15, 7
# Обработка
result = calculate(x, y, '*')
print(f"Результат вычислительной обработки: {x} * {y} = {result}")

# Демонстрация поиска (изменение формы)
data = [34, 7, 89, 12, 56, 3, 78]
query = 56
# Алгоритм поиска
found_index = -1
for i, value in enumerate(data):
    if value == query:
        found_index = i
        break
print(f"Поиск элемента {query}: найден на позиции {found_index}")

# Демонстрация сортировки (изменение формы)
sorted_data = sorted(data)
print(f"Отсортированные данные: {sorted_data}")

Задача 2. Понятия

Условие: Поясните суть понятий «кодирование», «код», «кодовая таблица».
Краткое решение
  • Кодирование — преобразование.
  • Код — система обозначений.
  • Таблица — соответствие.
Подробное решение

Кодирование — это процесс преобразования информации в форму, удобную для её хранения, передачи и автоматической обработки. Кодирование может быть обратимым (декодирование восстанавливает исходные данные) и необратимым (часть информации теряется, например, при сжатии с потерями).

Код — это система условных обозначений (символов, сигналов) и правил их сопоставления с элементами исходной информации. Примеры: азбука Морзе, двоичный код, штрих-код, QR-код.

Кодовая таблица — это совокупность всех используемых кодовых слов и соответствующих им значений. Она устанавливает взаимно однозначное соответствие между символами алфавита и их кодами. Пример: таблица ASCII, где каждому символу соответствует число от 0 до 127.

Свойства кода:

  • Однозначность — каждому символу соответствует ровно один код.
  • Обратимость — возможно однозначное декодирование.
  • Избыточность — может использоваться для обнаружения и исправления ошибок.
Программное решение (Python) 
# Пример кодирования и декодирования
# Кодовая таблица: буква -> код
code_table = {
    'А': '00',
    'Б': '01',
    'В': '10',
    'Г': '11'
}

# Функция кодирования
def encode(text):
    result = ''
    for char in text:
        if char in code_table:
            result += code_table[char]
    return result

# Функция декодирования
def decode(code):
    reverse_table = {v: k for k, v in code_table.items()}
    result = ''
    for i in range(0, len(code), 2):
        pair = code[i:i+2]
        if pair in reverse_table:
            result += reverse_table[pair]
    return result

# Исходный текст
original = 'АБВГ'
encoded = encode(original)
decoded = decode(encoded)

print(f"Исходный текст: {original}")
print(f"Кодовая таблица: {code_table}")
print(f"Закодированный текст: {encoded}")
print(f"Декодированный текст: {decoded}")

Вывод:

Исходный текст: АБВГ
Кодовая таблица: {'А': '00', 'Б': '01', 'В': '10', 'Г': '11'}
Закодированный текст: 00011011
Декодированный текст: АБВГ

Задача 3. Светодиодная панель

Условие: Светодиодная панель состоит из 6 элементов, каждый может гореть одним из трёх цветов. Сколько различных сигналов можно передать?
Краткое решение

N = 36 = 729.

Подробное решение

Анализ задачи. Каждый из 6 элементов независим от других и может принимать одно из 3 состояний (3 цвета). Это классическая задача на правило умножения: если объект A можно выбрать m способами, а объект B — n способами, то пару (A, B) можно выбрать m·n способами.

Применение правила умножения. Для первого элемента — 3 варианта. Для второго — тоже 3. И так далее для всех 6 элементов. Общее число комбинаций:

N = 3 · 3 · 3 · 3 · 3 · 3 = 36

Вычисление. 32 = 9, 33 = 27, 34 = 81, 35 = 243, 36 = 729.

Проверка через информационный объём. Один элемент несёт log23 ≈ 1.585 бит. Шесть элементов — 6 · log23 = log2729 ≈ 9.51 бит. Количество сигналов 29.51 ≈ 729. Совпадает.

Ответ: 729 различных сигналов.

import itertools

# Все возможные сигналы: перебор всех комбинаций
colors = ['R', 'G', 'B']  # Красный, Зелёный, Синий
count = 0

# Перебираем все комбинации из 6 элементов
for signal in itertools.product(colors, repeat=6):
    count += 1
    # Для наглядности выведем первые 5
    if count <= 5:
        print(f"Сигнал {count}: {signal}")

print(f"\nОбщее количество сигналов: {count}")

# Альтернативный способ через формулу
formula_count = 3 ** 6
print(f"По формуле 3^6 = {formula_count}")

# Проверка: количество сигналов, начинающихся с красного
red_start = sum(1 for s in itertools.product(colors, repeat=6) if s[0] == 'R')
print(f"Сигналов, начинающихся с красного: {red_start} (ожидается 3^5 = {3**5})")

Задача 4. Автомобильный номер

Условие: Автомобильный номер состоит из K букв и 3 цифр. Используется 5 различных букв и 10 цифр. Какое минимальное K нужно, чтобы можно было составить не менее 100 000 различных номеров?
Краткое решение

5K · 1000 ≥ 100 000 ⇒ K = 3.

Подробное решение

Анализ задачи. Номер состоит из двух частей: буквенной (K позиций) и цифровой (3 позиции). Буквы и цифры выбираются независимо. Используется 5 различных букв и 10 различных цифр.

Количество буквенных комбинаций. На каждой из K позиций может стоять любая из 5 букв. По правилу умножения:

Nбукв = 5K

Количество цифровых комбинаций. На каждой из 3 позиций может стоять любая из 10 цифр:

Nцифр = 103 = 1000

Общее количество номеров. Так как буквенная и цифровая части независимы, общее число номеров равно произведению:

N = 5K · 1000

Решение неравенства. По условию N ≥ 100 000:

5K · 1000 ≥ 100 000

5K ≥ 100

Подбор K. Проверим значения:

  • K = 2: 52 = 25 < 100 — не подходит.
  • K = 3: 53 = 125 ≥ 100 — подходит.

Проверка. При K = 3: N = 125 · 1000 = 125 000 ≥ 100 000. Условие выполнено. При K = 2: N = 25 · 1000 = 25 000 < 100 000. Не выполнено.

Ответ: K = 3.

Программное решение (Python) 
# Параметры задачи
letters = 5      # количество различных букв
digits = 10      # количество различных цифр
digit_positions = 3  # количество цифровых позиций
required = 100000    # минимальное количество номеров

# Подбираем минимальное K
K = 0
while True:
    K += 1
    total = (letters ** K) * (digits ** digit_positions)
    print(f"K = {K}: {letters}^{K} * {digits}^{digit_positions} = {letters**K} * {digits**digit_positions} = {total}")
    if total >= required:
        print(f"\nМинимальное K = {K}")
        print(f"Всего номеров: {total}")
        break

# Альтернативный расчёт через логарифмы
import math
min_K = math.ceil(math.log(required / (digits ** digit_positions), letters))
print(f"\nЧерез логарифмы: K = {min_K}")

K = 3: 5^3 * 10^3 = 125 * 1000 = 125000

Всего номеров: 125000

Через логарифмы: K = 3

Задача 5. Последовательности

Условие: Сколько существует 6-символьных последовательностей из алфавита {A, B, C, D}, содержащих не менее двух букв A?
Краткое решение

4096 - 729 - 1458 = 1909.

Подробное решение

Метод от противного. Проще посчитать общее число последовательностей и вычесть те, где букв A меньше двух (то есть 0 или 1).

Шаг 1. Общее количество последовательностей. Алфавит содержит 4 символа, длина 6. По правилу умножения:

Nвсего = 46 = 4096

Шаг 2. Последовательности без буквы A. Используются только B, C, D — 3 символа на 6 позициях:

N0A = 36 = 729

Шаг 3. Последовательности ровно с одной буквой A. Выбираем позицию для A (6 способов). На остальных 5 позициях — любые из 3 оставшихся букв (B, C, D):

N1A = 6 · 35 = 6 · 243 = 1458

Шаг 4. Искомое количество. Вычитаем не подходящие случаи:

N = 4096 - 729 - 1458 = 1909

Проверка через сумму. Разобьём на случаи «ровно 2 A», «ровно 3 A», ..., «ровно 6 A»:

  • Ровно 2 A: C(6,2) · 34 = 15 · 81 = 1215
  • Ровно 3 A: C(6,3) · 33 = 20 · 27 = 540
  • Ровно 4 A: C(6,4) · 32 = 15 · 9 = 135
  • Ровно 5 A: C(6,5) · 31 = 6 · 3 = 18
  • Ровно 6 A: C(6,6) · 30 = 1 · 1 = 1

Сумма: 1215 + 540 + 135 + 18 + 1 = 1909. Совпадает.

Ответ: 1909 последовательностей.

Программное решение (Python) 
import itertools

# Полный перебор
alphabet = 'ABCD'
count = 0
total = 0

for word in itertools.product(alphabet, repeat=6):
    total += 1
    if word.count('A') >= 2:
        count += 1

print(f"Всего последовательностей: {total}")
print(f"С не менее чем двумя A: {count}")

# Проверка через формулу
from math import comb
formula_count = sum(comb(6, k) * (3 ** (6 - k)) for k in range(2, 7))
print(f"По формуле: {formula_count}")

# Разбивка по количеству A
for k in range(7):
    c = sum(1 for w in itertools.product(alphabet, repeat=6) if w.count('A') == k)
    print(f"Ровно {k} букв A: {c}")

Задача 6. Коды

Условие: Сравните равномерные и неравномерные коды. Приведите примеры.
Краткое решение

Равномерные — простые, неравномерные — экономные.

Подробное решение

Равномерный код. Все кодовые слова имеют одинаковую длину. Пример — ASCII: каждый символ кодируется 8 битами (или 7 в оригинальной версии). Другой пример — двоичное кодирование чисел фиксированной разрядности.

Преимущества равномерного кода:

  • Простота кодирования и декодирования.
  • Не требует анализа при декодировании — всегда известно, сколько бит читать.
  • Удобство для аппаратной реализации.

Недостатки равномерного кода:

  • Неэффективность: если символы встречаются с разной частотой, частые символы занимают столько же места, сколько редкие.
  • Избыточность при передаче данных.

Неравномерный код. Кодовые слова имеют разную длину. Пример — азбука Морзе: «E» = «·» (1 символ), «T» = «−» (1 символ), «A» = «·−» (2 символа). Другой пример — коды Хаффмана.

Преимущества неравномерного кода:

  • Экономия: частые символы кодируются короче, что уменьшает среднюю длину сообщения.
  • Оптимальность для сжатия данных.

Недостатки неравномерного кода:

  • Сложность декодирования: нужно определять границы кодовых слов.
  • Требуется условие Фано или аналогичное для однозначности декодирования.

# Сравнение равномерного и неравномерного кодирования
text = "AAAAABBBCCD"

# Равномерный код: 4 символа -> 2 бита
uniform_table = {'A': '00', 'B': '01', 'C': '10', 'D': '11'}

# Неравномерный код (учитываем частоту: A чаще всего)
nonuniform_table = {'A': '0', 'B': '10', 'C': '110', 'D': '111'}

def encode(text, table):
    return ''.join(table[ch] for ch in text)

uniform_code = encode(text, uniform_table)
nonuniform_code = encode(text, nonuniform_table)

print(f"Исходный текст: {text}")
print(f"Длина текста: {len(text)} символов\n")

print(f"Равномерный код: {uniform_code}")
print(f"Длина: {len(uniform_code)} бит")
print(f"Средняя длина на символ: {len(uniform_code)/len(text):.2f} бит\n")

print(f"Неравномерный код: {nonuniform_code}")
print(f"Длина: {len(nonuniform_code)} бит")
print(f"Средняя длина на символ: {len(nonuniform_code)/len(text):.2f} бит\n")

print(f"Экономия: {len(uniform_code) - len(nonuniform_code)} бит "
      f"({(1 - len(nonuniform_code)/len(uniform_code))*100:.1f}%)")

Задача 7. Префиксные коды

Условие: Что такое префиксные коды? Сформулируйте условие Фано.
Краткое решение

Префиксный код — ни одно слово не начало другого.

Подробное решение

Префиксный код. Это код, в котором никакое кодовое слово не является началом (префиксом) другого кодового слова. Например, код {0, 10, 110, 111} является префиксным: «0» не является началом «10», «110» или «111»; «10» не является началом «110» или «111»; «110» не является началом «111». А вот код {0, 01, 10} не является префиксным, потому что «0» — начало «01».

Прямое условие Фано. Для однозначного декодирования сообщения достаточно, чтобы ни одно кодовое слово не было началом другого кодового слова. Это условие является достаточным, но не необходимым.

Обратное условие Фано. Ни одно кодовое слово не должно быть окончанием (суффиксом) другого кодового слова. Также обеспечивает однозначное декодирование.

Почему это работает. Если ни одно слово не является префиксом другого, то при чтении сообщения слева направо можно однозначно определить, где заканчивается одно кодовое слово и начинается следующее. Как только прочитанная последовательность бит совпадает с каким-либо кодовым словом, её можно сразу декодировать.

Дерево кодирования. Префиксные коды удобно представлять в виде двоичного дерева: каждый лист — кодовое слово, путь от корня до листа — код. Условие Фано означает, что кодовые слова находятся только в листьях дерева (не во внутренних вершинах).

Пример проверки. Код {00, 01, 10, 11} — префиксный (все слова длины 2). Код {0, 10, 110, 111} — префиксный. Код {0, 01, 011} — не префиксный, так как «0» — префикс «01» и «011».

Применение. Префиксные коды используются в алгоритмах сжатия (Хаффман), в телекоммуникациях, при передаче данных по каналам связи.

def is_prefix_code(codes):
    """Проверяет, является ли набор кодов префиксным"""
    for i, c1 in enumerate(codes):
        for j, c2 in enumerate(codes):
            if i != j and c2.startswith(c1):
                return False, f"'{c1}' является префиксом '{c2}'"
    return True, "Код является префиксным"

def decode(s, codes):
    """Декодирование префиксного кода"""
    reverse = {v: k for k, v in codes.items()}
    result = ""
    i = 0
    while i < len(s):
        for length in range(1, len(s) - i + 1):
            if s[i:i+length] in reverse:
                result += reverse[s[i:i+length]]
                i += length
                break
        else:
            return "Ошибка декодирования"
    return result

# Пример 1: префиксный код
codes1 = {'A': '0', 'B': '10', 'C': '110', 'D': '111'}
ok, msg = is_prefix_code(list(codes1.values()))
print(f"Код 1: {codes1}")
print(f"Проверка: {msg}\n")

# Пример 2: не префиксный код
codes2 = {'A': '0', 'B': '01', 'C': '10'}
ok, msg = is_prefix_code(list(codes2.values()))
print(f"Код 2: {codes2}")
print(f"Проверка: {msg}\n")

# Декодирование
encoded = "010110111"
decoded = decode(encoded, codes1)
print(f"Закодированное сообщение: {encoded}")
print(f"Декодированное: {decoded}")

Подробное решение

Анализ существующих кодов. Троичный алфавит {0, 1, 2}. Даны коды: А=0, Б=11, В=20, Г=21, Д=22. Проверим условие Фано для текущего набора: ни один код не является префиксом другого (0, 11, 20, 21, 22 — все различны и не начинаются друг с другом).

Буква А (код 0). Сократить до пустой строки нельзя — пустой код недопустим. Длина 1 уже минимальна.

Задача 12. Половинное деление

Условие: В упорядоченном массиве из 1000 элементов ищут число 590 методом половинного деления. Сколько сравнений потребуется?
Краткое решение

4 шага.

Подробное решение

Идея метода. Бинарный поиск работает на упорядоченном массиве. На каждом шаге сравниваем искомое значение с элементом в середине текущего диапазона и отбрасываем ту половину, где искомого быть не может.

Моделирование. Пусть массив содержит числа от 1 до 1000. Ищем 590.

Шаг 1. Диапазон [1, 1000]. Середина: (1 + 1000) / 2 = 500 (округление). Сравниваем 590 и 500. 590 > 500, значит, искомое в правой половине. Отбрасываем [1, 500].

Шаг 2. Диапазон [501, 1000]. Середина: (501 + 1000) / 2 ≈ 750. Сравниваем 590 и 750. 590 < 750, значит, искомое в левой половине. Отбрасываем [751, 1000].

Шаг 3. Диапазон [501, 750]. Середина: (501 + 750) / 2 ≈ 625. Сравниваем 590 и 625. 590 < 625, значит, искомое в левой половине. Отбрасываем [626, 750].

Шаг 4. Диапазон [501, 625]. Середина: (501 + 625) / 2 = 563. Сравниваем 590 и 563. 590 > 563, значит, искомое в правой половине. Отбрасываем [501, 563].

Шаг 5. Диапазон [564, 625]. Середина: (564 + 625) / 2 ≈ 594. Сравниваем 590 и 594. 590 < 594, отбрасываем [595, 625].

Шаг 6. Диапазон [564, 594]. Середина: (564 + 594) / 2 = 579. Сравниваем 590 и 579. 590 > 579, отбрасываем [564, 579].

Шаг 7. Диапазон [580, 594]. Середина: (580 + 594) / 2 = 587. Сравниваем 590 и 587. 590 > 587, отбрасываем [580, 587].

Шаг 8. Диапазон [588, 594]. Середина: (588 + 594) / 2 = 591. Сравниваем 590 и 591. 590 < 591, отбрасываем [591, 594].

Шаг 9. Диапазон [588, 590]. Середина: 589. Сравниваем 590 и 589. 590 > 589, отбрасываем [588, 589].

Шаг 10. Диапазон [590, 590]. Середина: 590. Совпадение! Поиск завершён.

Примечание. Точное число шагов зависит от способа округления середины. В общем случае для массива из N элементов бинарный поиск требует не более ⌈log₂N⌉ + 1 сравнений. Для N = 1000: log₂1000 ≈ 9.97, значит, около 10 сравнений.

def binary_search(arr, target):
    """Бинарный поиск с подсчётом сравнений"""
    low, high = 0, len(arr) - 1
    steps = 0
    while low <= high:
        steps += 1
        mid = (low + high) // 2
        print(f"  Шаг {steps}: диапазон [{arr[low]}, {arr[high]}], "
              f"середина = {arr[mid]}")
        if arr[mid] == target:
            print(f"  ✓ Найдено за {steps} шагов!")
            return mid, steps
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1, steps

# Массив от 1 до 1000
arr = list(range(1, 1001))
target = 590

index, steps = binary_search(arr, target)
print(f"\nИндекс: {index}, всего шагов: {steps}")

    """Проверяет условие Фано"""

ЕГЭ: Задача 3 (Тип 8)

Условие: Коды: A=00, B=01, C=10, D=11. Дана строка: 00101101. Расшифруйте её.
Решение вручную

Анализ кода. Все кодовые слова длины 2. Равномерный код, декодирование однозначно.

Разбиение строки. 00101101 (8 бит = 4 слова по 2 бита):

00 | 10 | 11 | 01

Декодирование:

  • 00 → A
  • 10 → C
  • 11 → D
  • 01 → B

Результат: A C D B.

Проверка. Закодируем ACDB: A=00, C=10, D=11, B=01 → 00101101. Совпадает.

Ответ: ACDB.

Программное решение (Python) 
codes = {'00': 'A', '01': 'B', '10': 'C', '11': 'D'}
s = "00101101"

# Декодирование
result = ""
i = 0
while i < len(s):
    pair = s[i:i+2]
    result += codes[pair]
    print(f"  {pair} → {codes[pair]}")
    i += 2

print(f"\nРезультат: {result}")

# Обратная проверка
reverse = {v: k for k, v in codes.items()}
encoded = ''.join(reverse[ch] for ch in result)
print(f"Обратное кодирование: {encoded}")
print(f"Совпадает: {encoded == s}")

# Альтернативная запись через генератор
result2 = ''.join(codes[s[i:i+2]] for i in range(0, len(s), 2))
print(f"Через генератор: {result2}")

ЕГЭ: Задача 4 (Тип 9)

Условие: Даны коды: А=0, Б=10, В=110. Найдите кратчайший код для Г, удовлетворяющий условию Фано.
Решение вручную

Анализ существующих кодов. Даны: 0, 10, 110. Построим дерево кодирования:

  • 0 — левая ветвь от корня (занята, код А).
  • 1 — правая ветвь (промежуточный узел).
  • 10 — левая ветвь от «1» (занята, код Б).
  • 11 — правая ветвь от «1» (промежуточный узел).
  • 110 — левая ветвь от «11» (занята, код В).
  • 111 — правая ветвь от «11» (свободна).

Проверка длин.

  • Длина 1: «0» занято. «1» — не может быть кодом, так как является префиксом для «10» и «110» (нарушение условия Фано).
  • Длина 2: «10» занято. «11» — не может быть кодом, так как является префиксом для «110».
  • Длина 3: «110» занято. «111» — свободно и не конфликтует.

Проверка 111. «111» не является префиксом ни одного из существующих кодов (0, 10, 110). Ни один из существующих кодов не является префиксом «111». Условие Фано выполнено.

Ответ: 111.

Программное решение (Python) 
codes = ['0', '10', '110']

def is_valid(new_code, existing):
    """Проверяет условие Фано"""
    for c in existing:
        if new_code.startswith(c) or c.startswith(new_code):
            return False, c
    return True, None

# Перебираем коды по возрастанию длины
for length in range(1, 7):
    print(f"Длина {length}:")
    found = False
    for i in range(2**length):
        code = bin(i)[2:].zfill(length)
        valid, conflict = is_valid(code, codes)
        if valid:
            print(f"  ✓ {code} — подходит")
            if not found:
                print(f"\nКратчайший код: {code}")
                found = True
                exit()
        else:
            print(f"  ✗ {code} — конфликт с {conflict}")
