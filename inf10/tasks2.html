Базовый Задача 1

В школьной базе данных каждый ученик получил идентификатор, состоящий ровно из 7 символов. Каждый такой идентификатор записывается минимально возможным и одинаковым целым количеством байт (посимвольное кодирование, все символы кодируются одинаковым и минимально возможным количеством бит). Определите объём памяти для хранения 250 идентификаторов. Ответ выразите в килобайтах.

ЕГЭ Задача 7 (№31508)

На предприятии каждой изготовленной детали присваивают серийный номер, состоящий из 157 символов. В базе данных для хранения каждого серийного номера отведено одинаковое и минимально возможное целое число байт. При этом используется посимвольное кодирование серийных номеров, все символы кодируются одинаковым и минимально возможным числом бит. Известно, что для хранения 12 450 серийных номеров отведено не более 955 Кбайт памяти. Определите максимально возможную мощность алфавита, используемого для записи серийных номеров. В ответе запишите только целое число.

Задача 1

  1. Мощность алфавита: 29 букв + 9 цифр = 38 символов.
  2. Бит на символ: 2⁵ = 32 < 38 ≤ 64 = 2⁶ → 6 бит.
  3. Бит на идентификатор: 7 × 6 = 42 бита.
  4. Байт на идентификатор: 42 / 8 = 5,25 → округляем вверх → 6 байт.
  5. Всего байт: 250 × 6 = 1500 байт.
  6. В килобайтах: 1500 / 1024 ≈ 1,46 Кбайт.
Ответ: 1500/1024 ≈ 1,46 Кбайт

Задача 7 (ЕГЭ №31508)

Обратная задача: известен объём, нужно найти мощность алфавита.

  1. Переведём лимит в байты: 955 × 1024 = 977 920 байт.
  2. Байт на один номер: 977 920 / 12 450 ≈ 78,55. Так как «не более», берём целое вниз → 78 байт.
  3. Переведём в биты: 78 × 8 = 624 бита.
  4. Бит на один символ: 624 / 157 ≈ 3,97 → 3 бита (4 бита не влезут в лимит).
  5. Максимальная мощность алфавита: 2³ = 8.
Здесь округление идёт вниз, потому что в условии «не более 955 Кбайт». Если взять 79 байт, объём превысит лимит.
Ответ: 8

Общие сведения

Бит на символ

bits = (alphabet - 1).bit_length()

Метод .bit_length() возвращает число бит для представления числа. Вычитание 1 убирает лишний бит для точных степеней двойки.

Округление бит вверх до байт

bytes = (bits + 7) // 8

Перевод в килобайты

kb = total_bytes / 1024
