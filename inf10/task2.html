Задача 1 — решение на Python

Идентификаторы по 7 символов, алфавит из 38 знаков, 250 идентификаторов.

Условие

В школьной базе данных каждый ученик получил идентификатор, состоящий ровно из 7 символов. В качестве символов используются все заглавные буквы русского алфавита, кроме «Ё», «Й», «Ъ» и «Ь» (29 букв), а также все десятичные цифры, кроме 0 (9 цифр). Каждый идентификатор записывается минимально возможным и одинаковым целым количеством байт. Определите объём памяти для хранения 250 идентификаторов. Ответ выразите в килобайтах.

Полный код с пояснениями

1 def solve(): объявляем функцию solve, чтобы код был оформлен аккуратно
2 alphabet = 29 + 9 мощность алфавита: 29 букв (33 − 4 исключённых) + 9 цифр (1–9) = 38 символов
3 bits = (alphabet - 1).bit_length() минимальное число бит на 1 символ: (38−1).bit_length() = 37.bit_length() = 6 бит
4 bits_per_id = 7 * bits бит на один идентификатор: 7 символов × 6 бит = 42 бита
5 bytes_per_id = (bits_per_id + 7) // 8 байт на идентификатор: (42+7)//8 = 49//8 = 6 байт (округление вверх)
6 total_bytes = 250 * bytes_per_id объём для 250 идентификаторов: 250 × 6 = 1500 байт
7 total_kb = total_bytes / 1024 перевод в килобайты: 1500 / 1024 ≈ 1,4648 Кбайт
8 print(f"Ответ: {total_bytes}/1024 ≈ {total_kb:.4f} Кбайт") вывод результата: f-строка подставляет значения, .4f — 4 знака после запятой
9 solve() вызов функции — запускаем решение

Вывод программы

Ответ: 1500/1024 ≈ 1.4648 Кбайт

Формула округления вверх для байт

В Python оператор // — это целочисленное деление с округлением вниз (floor). Чтобы округлить вверх (ceil) для положительных чисел, используют приём:

ceil(x / n) == (x + n - 1) // n

Для перевода бит в байты n = 8, значит:

bytes = (bits + 7) // 8

Проверка на примерах

bits Точный расчёт Формула (bits+7)//8 Верно?
42 42/8 = 5,25 → 6 (42+7)//8 = 49//8 = 6 ✅
48 48/8 = 6,00 → 6 (48+7)//8 = 55//8 = 6 ✅
36 36/8 = 4,50 → 5 (36+7)//8 = 43//8 = 5 ✅
32 32/8 = 4,00 → 4 (32+7)//8 = 39//8 = 4 ✅
33 33/8 = 4,125 → 5 (33+7)//8 = 40//8 = 5 ✅
Почему работает? Если bits уже кратно 8, то bits + 7 даёт число, которое при делении на 8 даёт то же частное (потому что остаток 7 «съедается»). Если не кратно — добавка 7 гарантированно переводит результат в следующее целое.

Альтернативы

Способ Код Комментарий
Формула с +7 (bits + 7) // 8 Классика, работает всегда
Модуль math math.ceil(bits / 8) Требует import math, чуть медленнее
Через divmod divmod(bits, 8)[0] + (1 if bits % 8 else 0) Громоздко, но наглядно

Итог

Ответ: 1500 байт = 1500/1024 ≈ 1,4648 Кбайт
