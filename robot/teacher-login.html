Редактор РобоЛистов и журнал результатов доступны только после входа по защищённой ссылке, отправленной на e-mail преподавателя.

01Ученикам не требуется учётная запись.
02Ссылка действительна только для адреса преподавателя.
03Права к журналу дополнительно проверяются политикой базы данных.

Получить ссылку входа

Введите служебный e-mail преподавателя. Supabase отправит одноразовую ссылку для входа.

Первый вход может потребовать подтверждения письма. В Supabase должны быть добавлены адрес GitHub Pages и локальный адрес в списке Redirect URLs.
